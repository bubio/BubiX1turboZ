# BubiX1turboZ ユーザーマニュアル

*[English version](UserManual.en.md)*

Sharp X1 turbo Z のマルチプラットフォームエミュレーター、BubiX1turboZ の使い方をまとめたものです。インストールから起動まわりの詰まりどころ、メニュー各項目の意味、対応フォーマットを扱います。

## インストール

[リリースページ](https://github.com/bubio/BubiX1turboZ/releases/latest)から環境に合った実行ファイルをダウンロードしてください。

| プラットフォーム | 実行ファイル |
| --- | --- |
| macOS (Apple Silicon) | DMG |
| Linux (amd64 / arm64) | AppImage / `.deb` / `.rpm` |
| Windows (x86_64) | ZIP |

### Linux でアーカイブ（7z / zip）を読み込むために

`.7z` / `.zip` 形式のディスクイメージやアーカイブを開くには、`bsdtar`（`libarchive-tools` パッケージ）または `7-Zip`（`p7zip-full` パッケージ）のいずれかがシステムに入っている必要があります。入っていない場合、該当ファイルを開こうとするとアラートが出て失敗します。macOS / Windows では同梱のライブラリで完結するため、追加インストールは不要です。

```shell
sudo apt install libarchive-tools
# または
sudo apt install p7zip-full
```

## ROM ファイル

起動には Sharp X1 turbo Z 実機の BIOS ROM が必要です（本アプリには同梱されません、各自でご用意ください）。

- `IPLROM.X1T`（必須。これが無いと起動時にアラートが出て終了します）
- `FNT0808.X1`
- `FNT0816.X1`
- `FNT1616.X1`

フォント ROM が無い場合は内蔵の代替フォントで動作しますが、実機のフォントとは見た目が異なります。`SUBROM` / `KBDROM` が無い場合も擬似サブ CPU モードで動作を継続します。

### 配置場所

一度アプリケーションを起動するとフォルダが自動的に作成されます。実行ファイルと同じ場所には何も置きません。

| プラットフォーム | ROM フォルダ |
| --- | --- |
| macOS | `~/Library/Application Support/BubiX1turboZ/roms/` |
| Linux | `~/.local/share/BubiX1turboZ/roms/` |
| Windows | `%LOCALAPPDATA%\BubiX1turboZ\roms\` |

同じ base ディレクトリの下に、以下のフォルダも作られます。

- `states/` — クイックセーブ／ステートセーブのファイル
- `extracted/` — `.7z` / `.zip` アーカイブから展開したディスクイメージ

ROM が見つからない場合に出るアラートの「ROM フォルダを開く」ボタンで、この `roms/` フォルダを直接開けます。

## ディスクイメージの挿入

`Disk -> FD0 / FD1` メニュー、またはウィンドウへのドラッグ＆ドロップで、以下のフォーマットを挿入できます。

- ディスクイメージ: `d88` / `d77` / `d8e` / `1dd` / `2d`
- アーカイブ: `7z` / `zip`
- プレイリスト: `m3u` / `m3u8`（複数ディスクをまとめて登録し、ゲーム側のディスク交換要求に応じて切り替える形式）

ドラッグ＆ドロップで挿入すると、自動的にリセットが実行されてそのまま起動します。

### 7z / zip アーカイブの展開について

`.7z` / `.zip` は挿入時に `extracted/` フォルダへ展開され、以後はその展開済みファイルを使います（一度展開すれば、次回以降は再展開しません）。**ゲームがそのディスクに書き込んだセーブデータは、この `extracted/` フォルダの中、つまりアプリ専用の保存領域に置かれます。** 元のアーカイブファイルを削除・移動してもゲーム自体は遊べますが、セーブデータだけを他の場所に持ち出したい場合は要注意です。

`Disk` メニューの「展開したディスクを書き出す…」から、これまでに展開したすべてのディスクを任意のフォルダへまとめて書き出せます。アーカイブを整理する前や、セーブデータだけ他の環境に移したいときに使ってください。

## 主なショートカット

| キー | 動作 |
| --- | --- |
| `Cmd+R` / `Ctrl+R` | リセット |
| `Cmd+V` / `Ctrl+V` | テキストの貼り付け（オートキー、クリップボードの内容をキー入力として流し込む） |
| `Cmd+S` / `Ctrl+S` | クイックセーブ |
| `Cmd+L` / `Ctrl+L` | クイックロード |
| `Cmd+1` / `Ctrl+1` | FD0 にディスクを挿入（ファイル選択ダイアログを開く） |
| `Cmd+2` / `Ctrl+2` | FD1 にディスクを挿入 |
| `Cmd+3` / `Ctrl+3` | FD0/FD1 両方に同じディスクを挿入 |
| `Cmd+Ctrl+F` | フルスクリーン切り替え |

これ以外のメニュー項目にもショートカットが割り当たっている場合がありますが、割り当てはメニューを開くと表示されるものが最新です。

## 設定項目

`Device` / `Host` メニューから変更できる主な設定です。

- **ディスプレイ解像度**（高解像度 / 標準）: X1turboZ 固有の 4096 色モードなど、機種の表示モードに関わる設定
- **サウンドボード**: 変更はメニュー上ですぐ反映されますが、実際にマシンへ組み込まれるのは次回のリセット（`コントロール > リセット`）時です。組み込み後に発音がおかしい場合は一度リセットしてください
- **走査線 / フィルタ（ニアレストネイバー・バイリニア）**: 表示の拡大方式
- **音量**: `Host > サウンド > 音量` からマスター音量と L/R リンクを調整
- **言語**: システムに従う / 日本語 / English から選択。切り替えは次回起動時に反映されます
- **キーボード**: カーソルキー／数字キーをテンキーとして使うかどうかの切り替え

## ステートセーブ／ロード

`コントロール > ステートを保存…` / `ステートを読み込み…` から、複数スロットへの保存・復元ができます。クイックセーブ／クイックロード（`Cmd/Ctrl+S` / `Cmd/Ctrl+L`）は専用の 1 スロットを使う簡易版です。

ステートファイルは本アプリ独自形式で、他のエミュレーターや異なるバージョンの BubiX1turboZ との互換性はありません。ROM のデータ自体はステートに含まれないため、保存時と異なる ROM で読み込むとマシンの状態が壊れる場合があります。読み込み時に問題が検出されると、内容を要約したメッセージが表示されます。

## 音声録音・スクリーンショット

`Host` メニューの「サウンドを録音」「画面を保存」から、それぞれ OS 標準の音楽フォルダ・画像フォルダに書き出されます（`roms/` などのアプリ専用フォルダとは別の場所です）。
